## Gate

## Authority

- canonical `pages/` records are textual authority;
- this layer may remove page-boundary friction for reading but may not silently rewrite source text;
- split-boundary provenance must remain auditable;
- illustrations/non-text matter must not generate invented prose.

Every Part assembly audit must establish:

- complete canonical scan coverage;
- omissions = 0;
- duplicates = 0;
- unsupported Tamil body insertion = 0;
- audit-note leakage = 0;
- canonical-page mutations caused by assembly = 0.
